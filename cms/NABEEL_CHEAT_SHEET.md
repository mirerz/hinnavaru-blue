# 🌊 Hinnavaru Blue: Nabeel's CMS Cheat Sheet

Welcome to the Hinnavaru Blue Initiative platform, Nabeel! This guide will help you manage the site content easily.

## 🛠️ The Toolbar Icons

At the top of the screen when you are logged in, you will see these icons:

1. **✏️ The Pencil (Edit Mode)**: Click this to start making changes to the current page. Once clicked, you can click on any "block" of text or image to edit it.
2. **➕ The Plus (Add Block)**: Click this to drag new things onto the page, like images, videos, or new paragraphs.
3. **📄 The Pages (Sitemap)**: Click this to add new pages or see the structure of the whole website.
4. **⚙️ The Gear (Page Settings)**: Use this to change the page title, description (for SEO), or to set a thumbnail image.

## 🚢 Publishing Workflow

Because we want to keep the live site pristine, your changes won't go live immediately:

1. **Make your edits** using the Pencil icon.
2. **Click "Save Changes"** (the green button that appears).
3. **Select "Submit to Workflow"**: This sends your changes to the Administrators for a quick review.
4. **Review Status**: Once an Admin approves, your changes will automatically appear on the live site!

## 📂 Uploading Content

- Use the **File Manager** in the Dashboard to upload new photos and videos.
- All your primary uploads should go into the **"HINNAVARU_CONTENT"** folder for better organization.
